# 文案审核

## 核心原则

> 别告诉观众你什么感觉，告诉观众你当时看见了什么、听见了什么、干了什么。感觉，让他们自己来。

直接说"我好感动""我太生气了"是结论，观众没感觉。把情绪词换成具体的画面、动作、原话，观众会自己走进场景，自己长出情绪。

---

## 审核流程（按顺序执行）

### 第一步：圈出所有情绪词，逐个替换

**情绪词清单**：感动、开心、难过、生气、愤怒、温暖、崩溃、破防、心酸、无奈、绝望、幸福、激动、失望……以及"人与人之间就应该这样""真的太那个了"等抽象结论。

**替换方法**：问自己——"我产生这个情绪的时候，正在做什么动作？"用动作代替情绪词。

| 原句（情绪词） | 改写（动作） |
|---|---|
| 我特别感动 | 我拿着那个东西在沙发上坐了十分钟，没说话 |
| 我太生气了 | 我挂了电话，在原地站了半分钟 |
| 我心里一酸 | 我把手机扣在桌上，深吸了一口气 |

### 第二步：圈出所有模糊词，补具体信息

**模糊词清单**：一个礼物、一件事、有个人、前段时间、最近、那天、某个东西、很好、很特别……

**替换方法**：问自己三个问题——
1. **到底是什么？**（具体物品/事件名称）
2. **谁干的？**（具体的人，身份或关系）
3. **什么时候？**（具体时间或场景）

| 原句（模糊） | 改写（具体） |
|---|---|
| 我收到一个礼物 | 我收到一个保温杯 |
| 有个人跟我说 | 我同事小王跟我说 |
| 前几天发生了一件事 | 上周三晚上下班的时候 |

### 第三步：检查五感细节，至少加一个

五感 = 看到的、听到的、摸到的、闻到的、尝到的。

**方法**：在关键场景里抓一个"看起来没用"的小细节放进去。越碎越真实。

| 维度 | 示例细节 |
|---|---|
| 看到 | 字写得歪歪扭扭的 / 包装纸边角皱了 |
| 听到 | 电话那头沉默了三秒 / 他叹了口气 |
| 摸到 | 杯子还温着 / 纸壳子被雨水泡软了 |
| 闻到 | 一股消毒水味 / 楼道里飘着炖肉香 |

### 第四步：检查有没有原话/对话

如果文案里涉及到另一个人说了什么，**必须用直接引语**，不要转述。

| 转述（没感觉） | 原话（有冲击力） |
|---|---|
| 狗主人态度很恶劣 | 狗主人说："这有什么呢？大惊小怪的，我女儿一年被咬好多次都没事" |
| 他说了些风凉话 | 他说："至于吗？不就碰了一下" |
| 妈妈一直叮嘱我 | 妈妈在电话里说："钱不够跟妈说，别硬撑" |

### 第五步：检查有没有冲突/对立面

好文案天然有张力。检查：
- 有没有一个"对立面"（某个人、某种态度、某个规则）？
- 有没有"应该怎样但实际怎样"的落差？

如果没有，考虑是否能补一个。冲突让观众自动站队，站队就产生了代入。

---

## 输出格式

审核完成后，按以下结构输出：

### 1. 问题诊断
逐条列出文案中存在的问题，标注位置和类型（情绪词/模糊词/缺细节/缺原话/缺冲突）。

### 2. 改写版本
给出完整改写后的文案。

### 3. 改写说明
简要说明每处关键改动为什么这么改（对应哪一步技巧）。

---

## 完整示例

**原文：**
> 我前两天收到了一个礼物，我特别的感动，我觉得人与人之间就应该这样。

**问题诊断：**
- "特别的感动"——情绪词，直接宣告结论
- "一个礼物"——模糊词，不知道是什么
- "人与人之间就应该这样"——抽象结论，无画面
- 缺少细节、原话、冲突

**改写版本：**
> 我前两天收到个快递，拆开是个保温杯。我三个月前随口跟她说过一次，说我天天喝凉水胃不舒服。盒子里还有张纸条，字写得歪歪扭扭的，就四个字：记得喝热水。我拿着杯子在沙发上坐了十分钟，没说话。

**改写说明：**
- "感动"→"在沙发上坐了十分钟没说话"（第一步：动作代替情绪）
- "一个礼物"→"保温杯"+"三个月前随口说过"（第二步：补具体信息）
- 加了"字写得歪歪扭扭"（第三步：五感细节）
- 加了"记得喝热水"原话（第四步：直接引语）
- 全文没说一个"感动"，但观众自己会感动

## 自检口诀

写完文案后，逐句问三个问题：
1. 这句话里有没有情绪词？→ 有就换成动作
2. 我说的东西具体吗？→ 模糊就补"什么/谁/什么时候"
3. 有没有一句原话或一个小细节？→ 没有就加一个
