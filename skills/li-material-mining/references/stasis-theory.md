# 争点理论地图

仅在需要解释争点分类、讲述框架、关注度或证据检查时读取。理论用于改变角度选择，不用于给正文增加权威感。

## 1．Stasis Theory

传统修辞学的争点理论通常追溯到 Hermagoras，并由 Cicero、Quintilian 等人保存和发展。它帮助辩论者先确定双方究竟在哪一层发生分歧。

本 Skill 使用四类：

| Stasis | 当前用法 | 典型问题 |
| --- | --- | --- |
| Conjecture | 事实争点 | 发生了吗？过程和因果是什么？ |
| Definition | 定义争点 | 这件事应归入什么概念？ |
| Quality | 价值争点 | 它是否合理、重要、可责或可原谅？ |
| Translation／Procedure | 行动争点 | 谁该处理？应该怎样回应或改变？ |

它负责扩大争点候选空间。事实不足时，不能跳过事实层直接给人物定性。

参考来源：

- Cicero，*De Inventione*；
- Quintilian，*Institutio Oratoria*，Book III；
- Jeanne Fahnestock，*Rhetorical Style: The Uses of Language in Persuasion*，2011，可用于理解修辞选择与论证表达。

## 2．框架理论

Robert M. Entman 在 1993 年的〈Framing: Toward Clarification of a Fractured Paradigm〉中，将框架概括为选择并凸显现实的某些部分，从而定义问题、解释原因、作出评价并提出处理方向。

本 Skill 用它检查：

- 当前把什么定义成了问题；
- 原因和责任被归给谁；
- 采用了什么价值评价；
- 希望观众形成什么判断或行动。

框架能够改变注意力分配，不能证明框架中的事实或因果自动成立。

## 3．新闻价值

Galtung 与 Ruge 在 1965 年研究新闻选择因素；后续研究持续修订新闻价值。与本 Skill 直接相关的信号包括冲突、意外、精英人物、个人化、接近性和影响范围。

本 Skill 用它判断观众为什么会注意某个候选。高知名度人物能够提高入口强度，但不能替代公共问题、证据和用户立场。

参考来源：

- Johan Galtung、Mari Holmboe Ruge，〈The Structure of Foreign News〉，1965；
- Tony Harcup、Deirdre O’Neill，〈What Is News? News Values Revisited (Again)〉，2017。

## 4．Toulmin 论证模型

Stephen Toulmin 在 *The Uses of Argument*（1958）中区分主张、材料、论证桥梁、支持、限定和反驳。

本 Skill 用它检查：

```text
事实材料 → 凭什么支持当前主张 → 主张需要怎样限定 → 什么反例会削弱它
```

如果候选只能依靠“我感觉”“他肯定是因为……”成立，就缺少可靠的论证桥梁，应降级或改写成第一人称体验。

## 组合方式

1. Stasis 生成不同层级的争点；
2. 框架理论把争点组织成观众能进入的问题；
3. 新闻价值判断入口强度；
4. Toulmin 模型和风险扣分阻止无证据指控。

组合类型：顺序执行，并在证据检查失败时退回事实争点或第一人称经验。
