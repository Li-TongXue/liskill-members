# 平台规则速查（抖音 / 微信视频号 / 小红书 + 通用法规）

> 使用说明：审核时按本文件核对平台差异。条款编号指向各平台官方规范原文。平台规则为动态文档，输出报告时对时效性强的依据可标注「依据待核实」。

## 1. 抖音

**官方依据**：《抖音社区自律公约》《抖音用户服务协议》＋平台审核规则、电商内容规则、AI 内容标注规则。

### 1.1 公约禁止行为（摘要）
- 危害国家及社会安全：反对宪法基本原则、危害国家安全、损害国家形象、煽动民族仇恨、破坏宗教政策 / 宣扬邪教迷信、煽动非法集会、侮辱诽谤他人等。
- 开展传播违法犯罪：宣扬暴力恐怖极端、歪曲丑化英雄烈士、借重大活动 / 英雄烈士商业营销、淫秽色情赌博毒品、伪造人民币、非法募捐、群架斗殴、诈骗传销走私、违法销售禁限商品（枪支弹药、管制刀具、野生动植物、医疗服务、医美、器械、药品保健品、三无产品、烟草等）。
- 危及未成年人：未成年人色情低俗、侵害未成年人权益、未成年人不当行为、诱导饭圈互撕、无底线追星打榜、诱导未成年人应援集资等。
- 危险行为：厌世轻生情绪、自残自虐自杀展示、血腥暴力惊悚、美化自我伤害或饮食障碍。
- 不合规医疗：见违禁词库「医疗功效词」部分；仅认证用户可发医疗内容；禁医生推销；恶性肿瘤仅允许预防 / 早筛科普。
- 违背诚信：侵权（名誉肖像隐私专利著作权商标）、散播谣言、虚假数据作弊、买卖账号养号。
- 不良价值观：软色情低俗、畸形婚恋观 / 情感操控课程、地域民族群体歧视、丧葬卖惨、炫富拜金、偷拍隐私、动物不当内容、饭圈极端行为。
- 不利于生态：过度营销导流、视频含联系方式 / 二维码 / 链接、批量低质同质化内容、骚扰他人、手术 / 纹身 / 伤口等不适内容。

### 1.2 不欢迎行为（降权 / 限流级）
借社会负面事件营销、危险动作（危险驾驶、燃柳絮、人群点爆竹、恶意整蛊）、哗众取宠恶意审丑、过度炒作明星绯闻、低质搬运（带其他平台水印）、医疗医美夸大、照搬他人创意文案。

### 1.3 内容表达规范
- 重视文字正确使用：避免错别字、拼音首字母缩写，治理"黑话烂梗"（2025 年起持续整治）。
- 倡导原创优质、真人出镜、真实表达，反对卖惨博眼球、虚假人设。

### 1.4 AI 生成内容标识（重点）
- 凡 AI 生成 / 辅助内容（AI 画面、AI 配音、AI 写脚本、AI 剪辑、数字人、AI 换脸）发布时必须**在发布页勾选平台 AI 生成标识**，且建议在视频前 5 秒显著标注"本视频含 AI 生成内容"。
- 仅在画面打字或简介备注不算有效标注，以发布页系统勾选为准。
- 处罚梯度：漏标→下架 + 限流；再次→封挂车 / 橱窗；AI 换脸 / 深度合成不标注更重，可限制投稿甚至封号。
- 法律依据：《人工智能生成合成内容标识办法》（2025-09-01 起，公开的 AI 生成内容需显式 + 隐式标识）。

### 1.5 电商 / 带货红线
- 极限词、绝对化用语（"最有效""第一""顶级""全网最低价"）禁说。
- 虚假宣传：清仓演戏、卖惨、编造销量、伪造证件、夸大效果均违规；价格优惠须与详情页一致；禁"内部券"话术。
- 无资质售卖药品 / 器械 / 医美：轻则商品下架扣分，重则永久取消带货资格、扣保证金。
- 引导站外私下交易、留联系方式为红线。

### 1.6 处罚机制
删除 / 屏蔽、暂停功能、扣信用分、限流、下架、封禁橱窗、封号；屡犯或恶劣者保存记录并报告主管部门。

## 2. 微信视频号

**官方依据**：《微信视频号运营规范》（规范条款编号如 5.2 / 5.9 / 5.10 / 5.15-5.20）、《视频号常见违规内容概览》、《视频号信用分运营规范》。

### 2.1 账号规范（第三章）
- 一微信号一视频号；名称须与简介相符、客观可识别，禁止夸大性 / 误导性 / 过度广告性表述；禁止仿冒公众人物。
- 名称禁用：国家名称 / 国旗国徽军旗勋章、外国国名、民族歧视性、夸大欺骗性（如"国酒""中国第一酒"）、有害公序良俗、歧义误导、通用名词（正能量 / 吃货 / 星座 / 养生 / 百科等）、单独地域名、为违法沟通便利的命名。
- 禁止明星艺人打投 / 集资 / 控评 / 八卦 / 爆料类账号；未授权不得建粉丝团 / 后援会。

### 2.2 禁止恶意使用（第四章）
不当注册、篡改功能、使用外挂、**诱导用户**（利诱分享点赞关注：拆礼盒、集赞、分享加抽奖；胁迫："不点赞全家死光光""不点赞不是中国人"；诱导未成年人应援；煽情交友诱导联系）、刷量刷粉、违法营销（诈骗传销走私、禁限商品、**未经许可荐股 / 推荐金融产品 / 以财经分享诱导引流**、违反广告法）、**恶意对抗（变体规避审核）**、干扰用户（骚扰信息、特殊识别码口令、违规外链）、不实身份、人身攻击、欺诈。

### 2.3 不得传播不良信息（第五章，审核核心）
- 5.1 国家法律法规禁止内容。
- 5.2 生态不良：标题党（夸张标题与内容不符）、炒作绯闻丑闻、不当评述灾难、性暗示性挑逗、血腥惊悚、煽动地域歧视、低俗庸俗媚俗、诱导未成年人模仿不安全行为。
- 5.3 侵犯他人权利：抄袭搬运、泄露隐私（身份证 / 联系方式 / 住址 / 微信号 / 照片）、侮辱诽谤（含粉丝互撕谩骂拉踩引战）、泄露商业秘密。
- 5.4 不实信息（政治类 / 煽动仇恨 / 扰乱秩序 / 迷信 / 常识类）。
- 5.5 骚扰煽动夸大误导：惊悚极端标题、侮辱脏话、煽动行为、误导时效事件、编造夸张猎奇引战故事（夸张炫富、快速赚钱经历）。
- 5.7 未成年人：虐待体罚、性侵害、校园欺凌、推销危害玩具、饮酒吸烟吸毒、披露隐私、未成年人婚育、厌学弃学、歪曲恶搞经典卡通、利用未成年人恶俗表演。
- 5.8 令人极度不适：自残自杀被杀、毒品、枪击、尸体骷髅、家暴校园暴力斗殴。
- 5.9 低俗：衣着暴露、性暗示、侮辱性羞辱性用语、违背伦理（婚外恋、婚闹、童养媳）、动物交配细节、聚焦两性隐私、情趣用品露骨介绍。
- 5.10 卖惨扮丑：利用未成年 / 残障骗取同情、卖惨式推广、疾病贫穷道德绑架、刻意扮丑。
- 5.11 描述 / 话题 / 链接与内容不符：夸张诱惑词汇、隐藏关键信息、无关联链接、配音与画面不相关。
- 5.12 批量同质化内容（侵害知识产权 / 降低体验 / 骚扰）。
- 5.13 伪科学：恐怖灵异、风水运势、食物相克。
- 5.14 低质：轮播文字大字覆盖、画质模糊、音画不相关、过度剪裁、混剪拼接杜撰名人名言、严重过时新闻。
- 5.15-5.20 不规范医疗科普（科学性错误 / 片面夸大 / 不符中医理论 / 医疗风险 / 医疗营销 / 医疗引流）。
- 5.21 其他见《视频号常见违规内容概览》。

### 2.4 AI 内容标识（6.4）
- 深度合成 / 生成式 AI 生成或合成的非真实音视频、剧情演绎虚构内容，须**显著方式标识**，避免误导。
- 未标识或利用 AI 虚假摆拍获取流量不当营销，平台有权处罚；"AI 魔改"经典影视、历史名人 / 英模、未成年人动画形象为专项治理对象（2026 年 9 月集中清理）。

### 2.5 信用分（《视频号信用分运营规范》扣分示例）
政治敏感 10 分｜色情违规 20 分｜违法违规 20 分｜对抗规则 40 分｜疑似不实 / 夸大 / 虚假 10 分｜违法违规或敏感内容 5 分｜低俗或过度暴露 5 分｜过度营销或骚扰 5 分｜违规诱导 5 分。

### 2.6 处罚机制
减少推荐、删除内容、限制功能、暂停 / 终止服务、封禁账号、禁止再注册；认证主体对账号行为担责。

## 3. 小红书

**官方依据**：《小红书社区公约 2.0》（2026-01 上线，25 条倡导）、《小红书交易导流违规管理细则》、《小红书社区金融生态公约》（2026-09）及平台审核机制。

### 3.1 社区公约 2.0（价值观与倡导）
- 三板块：真诚分享 / 友好互动 / 有序经营。
- 核心倡导：**反对制造对立**、拒绝虚假人设、反对网暴、保护未成年人、反对虚假营销和恶意竞争、**主动标明 AI 辅助工具创作**、不贬低竞争对手、不编造不实信息、不滥用举报、不攀附其他品牌营销、通过平台工具完成交易。
- 尊重不同性别、地域、种族、职业和兴趣；不轻易利用影响力指控或发布煽动性话语。

### 3.2 审核机制（重点）
- 机器（NLP 关键词库 + 语义识别 + 变体识别）＋人工双重校验。
- **谐音、拼音、符号替换、拆分字变体全部可识别**（2026 升级），无漏洞。
- 违规后果：笔记限流 / 隐藏曝光 / 下架，账号 7-30 天限流，严重永久封禁、取消品牌合作权限、信用分处罚。

### 3.3 交易导流红线（《交易导流违规管理细则》）
- 禁止通过笔记、评论、私信、个人资料、群聊、瞬间打卡等任何形式，引导用户至私域或站外三方平台交易。
- 违规形式：展示站外导流信息（手机号、二维码、微信号等）；话术间接诱导（"私我""看我主页"）；大小号配合导流（大号建群小号引流）；暗示索取信息。
- 处罚：警告、禁言、**永久封号**。

### 3.4 诱导互动敏感
"评论区扣 1""点赞关注领资料""互关互赞""分享抽奖"等话术易被判定干扰用户体验，导致限流。

### 3.5 金融专项（《社区金融生态公约》）
- 划分鼓励的专业内容与禁止内容（非法荐股等八类禁止）。
- 金融营销需合规，禁止荐股、承诺收益、诱导开户等。

### 3.6 行业专项
- 美妆 / 食品 / 母婴功效词审核极细（见行业专项文件）。
- 达人禁止推广三品一械（药品、医疗器械、医美、保健食品），仅官方店铺合规报备可发科普。
- 制造焦虑话术（"再不护理就烂脸""孩子落后一辈子"）严控。
- 真人实测夸大（"所有人用完都变白"）无凭证限流。

### 3.7 处罚机制
限流、隐藏、下架、禁言（7-30 天）、取消品牌合作、永久封号；导流类处罚最重。

## 4. 通用法规与国标

| 法规 / 标准 | 与审核相关的要点 |
|---|---|
| 《广告法》 | 第 9 条：极限绝对化用语禁止；虚假广告禁止；医疗 / 药品 / 医疗器械 / 保健食品广告特殊限制（第 16-19 条）；广告不得含有"驰名商标"字样等 |
| 《反不正当竞争法》 | 虚假宣传、有奖销售（最高奖不超 5 万元） |
| 《互联网广告管理办法》 | 广告须具有可识别性，不得以知识介绍 / 测评等形式变相发布广告 |
| 《网络信息内容生态治理规定》 | 网络信息内容生产者不得制作复制发布传播违法信息、防范和抵制不良信息 |
| 《个人信息保护法》 | 未经同意不得处理、公开他人个人信息（含人脸、联系方式） |
| 《未成年人保护法》 | 网络保护专章：不得发布危害未成年人身心健康内容 |
| 《人工智能生成合成内容标识办法》 | 2025-09-01 施行：AI 生成内容需显式标识 + 隐式标识（元数据） |
| 广电总局 AI 相关治理要求 | AI 魔改经典影视、英模、儿童动画为专项治理对象 |

**引用规范**：报告中法规类依据标【已确认适用规则】；平台规则（可能频繁更新、或仅适用于特定平台）标【需核实是否适用规则】，并注明条款编号。
