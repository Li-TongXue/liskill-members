## 1. 标题党与题文不符（🟠）

**识别要点**：
- 夸张 / 惊悚 / 极端标题，内容与标题严重不符（视频号规范 5.2.1、5.11）。
- 封面外显反转、反话制造悬念，点击后货不对板（小红书审核规则明确禁止）。
- 故意隐藏关键信息、用指代不明或模糊词汇作描述。
- 用"震惊""紧急""速看""删前速存"等诱导点击。
- 添加的话题 / 描述与实际内容无关。

**平台差异**：三平台均禁；小红书对"制造悬念式标题、题文不符"单独列条；视频号 5.11 列出四项具体情形。

**风险等级**：🟠 中（限流 / 隐藏），题文严重不符可升级 🔴。

## 2. 诱导互动（🟠）

**识别要点**：
- 利诱分享 / 关注 / 点赞 / 评论：点赞关注领资料、评论区扣 1、分享抽奖、集赞、拆礼盒、加粉丝团领福利。
- 胁迫或煽动转发："不点赞不是中国人""不转发全家……""是中国人就扩散"（视频号 4.4.2 明文示例）。
- 频繁求关注、求三连（硬性话术）。
- 诱导未成年人应援消费。

**平台差异**：**小红书对诱导互动最敏感**（"评论区扣 1""互关互赞"易限流）；抖音不欢迎"视频内容诱导他人关注点赞评论"；视频号列入"诱导用户"恶意使用。

**风险等级**：🟠 中；胁迫话术 🔴。

## 3. 导流与站外交易（🔴）

**识别要点**：
- 明示：手机号、微信号、二维码、网址、公众号、淘宝 / 拼多多 / 闲鱼链接。
- 暗示："私我""看我主页""主页有惊喜""评论区留言""加微详聊""V 我"。
- 私域承接：进群、加群、粉丝群拉人、大小号配合。
- 交易导流：诱导线下交易、私下转账、货到付款、同城自提。

**平台差异**：**小红书最严**（《交易导流违规管理细则》可永久封号）；抖音电商规则禁站外私下交易、视频禁含联系方式；视频号短视频封面 / 标题禁留联系方式，禁止"附近 100 米""加微"类引流。

**风险等级**：🔴 高（小红书直接封禁级）。

## 4. 卖惨博同情与虚假人设（🟠→🔴）

**识别要点**：
- 编造或夸大疾病、贫穷、身世博同情（视频号 5.10 专项）。
- 利用未成年人、残障人士、老人骗取同情和流量。
- "卖惨式"推广商品（边哭边卖货、惨状营销）。
- 道德绑架："不买就是不爱……"
- 虚假人设：编造职业、经历、身份、收入（小红书公约 2.0"拒绝虚假人设"）。
- 刻意扮丑、恶意审丑博眼球。

**平台差异**：视频号 5.10 列专项；抖音"不欢迎"清单含"哗众取宠、恶意审丑""虚假做作、卖惨博人眼球的伪纪实"；小红书公约 2.0 明确拒绝虚假人设与过度包装。

**风险等级**：🟠 中，涉及未成年人 / 残障 / 疾病诈骗 🔴。

## 5. 制造对立与引战（🔴）

**识别要点**：
- 性别对立："男人都是……""女人就……"
- 地域黑：地图炮表述。
- 饭圈拉踩、引战、互撕、煽动粉丝仇恨。
- 职业 / 群体攻击：攻击特定职业、群体、残障人士。
- 贬低同行 / 竞品："XX 就是智商税""买 XX 的都是韭菜"。
- 挑拨民族、种族关系。

**平台差异**：小红书公约 2.0 首倡"反对制造对立"；抖音公约禁"煽动不同粉丝群体间仇恨敌视情绪""地域、民族、种族、针对某一群体恶搞、歧视类内容"；视频号 5.2.6 / 5.3.3 禁煽动歧视与粉丝互撕。

**风险等级**：🔴 高。

## 6. 炫富拜金与畸形价值观（🟠）

**识别要点**：
- 宣扬炫富、拜金主义、奢靡生活方式（视频号运营规范不良价值观相关条款）。
- 畸形婚恋观：宣扬婚外恋、PUA、情感操控课程（抖音公约明确禁止"传播、开展情感操控课程"）。
- 夸张炫富、快速赚钱经历引战（视频号 5.5.4 示例）。
- 低俗婚闹等落后糟粕。

**平台差异**：三平台均禁止不良价值观；抖音公约"传播不良价值观"章节明确；视频号运营规范第五章列出多项。

**风险等级**：🟠 中；PUA / 情感操控课程 🔴。

## 7. 危险行为与模仿风险（🟠→🔴）

**识别要点**：
- 危险驾驶（开车拍视频、追逐竞驶、醉驾）、危险挑战（高楼跑酷、无保护攀岩、极端恶作剧）。
- 教学 / 展示危险动作：燃柳絮、人群点爆竹、自制危险装置。
- 高危运动教学（非专业人士演示滑翔伞、跳伞、跳水等）。
- 恶搞他人造成伤害风险。

**平台差异**：抖音"不欢迎"清单列"危险动作、具有安全隐患的危险动作"；视频号常见违规内容概览"易引起模仿的危险内容"专项。

**风险等级**：🟠 中；易造成人身伤害 🔴。

## 8. 恐慌营销与借势（🔴）

**识别要点**：
- 借疫情、自然灾害、重大事故煽动抢购、制造恐慌（小红书社区规则：不得借疫情煽动抢购、营造恐慌营销）。
- 借社会负面事件、敏感事件商业营销（抖音"不欢迎"清单）。
- 不当评述灾难、调侃天灾人祸（视频号 5.2.3、常见违规内容概览）。
- "再不买就……"配合灾难语境。

**平台差异**：三平台一致禁止；视频号 5.2.3"不当评述自然灾害、重大事故等灾难"。

**风险等级**：🔴 高。

## 9. 低质内容与搬运（🟠）

**识别要点**：
- 搬运他人视频（带其他平台水印、直接下载混剪）。
- 低成本二次创作无增量：加边框、裁剪、镜像、简易转场、变速、改字幕（视频号常见违规概览 2.2.1 明示）。
- 批量同质化内容：近似情景、文案、元素批量编造。
- 照搬他人创意和文案（抖音"不欢迎"清单）。
- 轮播文字、大字覆盖、画质模糊、音画不相关。

**平台差异**：三平台均治理；视频号对"低成本二次创作"定义最细；抖音单列"刻意照搬、模仿他人创意和文案"。

**风险等级**：🟠 中；批量搬运 🔴（可能封号）。

## 10. AI 内容未标识（🔴）

**识别要点**：
- 文案 / 画面 / 配音 / 剪辑 / 数字人由 AI 生成或辅助，发布时未勾选平台 AI 生成标识。
- 仅在视频画面打字、简介备注不算有效标注（以发布页系统勾选为准，抖音 2026 新规）。
- AI 换脸、深度合成内容未标识（处罚最重）。
- AI 魔改经典影视 / 历史名人 / 英模 / 儿童动画（专项治理）。

**平台差异**：抖音（AI 内容强制标注，漏标下架 / 限流 / 封挂车）、视频号（运营规范 6.4 显著标识）、小红书（公约 2.0 主动标明 AI 辅助工具创作）均要求；法律依据《人工智能生成合成内容标识办法》。

**风险等级**：🔴 高。

## 11. 侵权风险（🔴）

**识别要点**：
- 文案抄袭：直接搬用他人文案、洗稿。
- 素材盗用：未经授权使用他人视频、图片、音乐、字体。
- 肖像侵权：未经同意拍摄 / 使用他人肖像（含路人特写、偷拍）。
- 冒用身份：仿冒他人、冒充官方 / 媒体 / 专家。
- 商标 / 品牌：未经授权使用他人商标、攀附品牌。
- 转播他人内容、赛事演出未授权。

**平台差异**：三平台一致禁止；视频号常见违规概览第 2 类"侵权内容"定义最细（含"低成本二次创作"侵权认定）。

**风险等级**：🔴 高（可下架 + 扣分 + 民事赔偿风险）。

## 12. 未成年人相关内容（🔴）

**识别要点**：
- 未成年人出镜未获监护人同意（尤其视频号 6.6：发布未成年人素材应取得权利人同意）。
- 利用未成年人博流量、卖惨、当模特 / 演员 / 代言。
- 展示未成年人不当行为：抽烟、喝酒、过密行为。
- 未成年人婚育、厌学弃学、参与饭圈集资打榜。
- 面向未成年人的焦虑营销（教育 / 母婴）。

**平台差异**：三平台均设未成年人保护专项；视频号对未成年人素材发布有专门同意要求；抖音有青少年模式与未成年人内容管理规范。

**风险等级**：🔴 高。

---

## 13. 无资质发布（敏感领域）（🔴）

**识别要点**：以下领域无相应资质 / 认证时发布即违规：
- 医疗健康：疾病预防、诊断、治疗、用药建议（抖音仅认证用户可发；视频号无资质发食疗 / 治疗方案 / 用药指导即违规）。
- 金融财经：荐股、推荐基金 / 期货 / 理财产品、以财经分享引流营销（视频号 4.6.2；小红书金融公约）。
- 时政新闻：无新闻资质发布时政、军事、社会新闻（视频号加热要求明文禁止）。
- 法律咨询：以律师身份给法律意见（无执业资质）。
- 三品一械带货：药品、医疗器械、医美、保健食品（小红书达人禁推）。
- 其他特许行业：教育培训承诺、资源回收、烟草酒类销售等。

**风险等级**：🔴 高（违规即处罚，重则封号 / 承担法律责任）。

## 14. 虚假数据与效果承诺（🟠→🔴）

**识别要点**：
- 编造 / 夸大销量、好评率、回购率："一千万人正在购买""好评率超 95%""XX 榜单第一"（视频号 4.11.1 案例）。
- 无凭证的"实测"："所有人用完都变白""全闺蜜实测零差评"。
- 效果承诺：三天见效、无效退款、包治、保过、稳赚。
- 价格与链接不符：视频说买一送一，链接无赠品。

**平台差异**：三平台一致禁止虚假宣传；小红书对"真人实测夸大"2026 年专项严控。

**风险等级**：🟠 中；医疗 / 金融效果承诺 🔴。
