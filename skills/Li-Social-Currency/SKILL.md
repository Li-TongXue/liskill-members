# Li-社交货币性选题内容判断

## 底层逻辑：先懂这一句，再用三个机制

> **人不是在分享你的视频，人是在经营自己的形象。**

观众每转发一次，都是在向朋友展示"我是什么样的人"。你的内容是观众拿去**花**的货币：花出去能换来别人对他的好印象，他就转；花出去丢人，内容再好他也不转。

所以判断分享性，永远不问"我的内容好不好"，只问：

> **观众把这条转出去，他在朋友面前是个什么样的人？**

---

## 三个机制（每个机制 = 帮观众扮演一种社交角色）

| 机制 | 本质 | 转发者扮演的角色 | 自检问题 |
|---|---|---|---|
| **内在非凡性** | 让人说出去有面子，能当谈资 | 见多识广、有意思的人 | 观众在饭桌上复述核心观点，对面会说"真的假的？"还是"哦"？ |
| **杠杆机制** | 给人一个体面展示自己的舞台（测试、排名、挑战、对比） | 很厉害 / 很特别的人 | 观众能不能借我的框架"顺便"描述或炫耀一下自己？ |
| **内部人感** | 让人觉得拿到了不是谁都知道的信息 | 有门路、有内部消息的人 | 转给朋友像不像递了一份"内部消息"的人情？ |

### 内在非凡性
公式：**预期 ≠ 现实 = 值得说出去**。打破常识、反直觉、低投入高产出的反差。
关键不是信息多奇怪，而是**能不能被复述成一句让对面接话的话**。

### 杠杆机制
MBTI 火，不是因为人在意类型，而是测完可以发。直接说"我很厉害"太赤裸，你的视频给了一个**合理的展示入口**。

### 内部人感
关键不在信息是不是真的"内幕"，而在表达方式有没有让人产生"我拿到了独家信息"的感觉。
**限制**：内部人感靠身份背书撑着。没有对应的从业经验 / 权威时，用它容易显得说教、端着，也没人信。**不要编造背书。**

---

## 三种用法

| 用法 | 起点 | 做什么 |
|---|---|---|
| **判断** | 已有一个或多个选题 / 一段内容 | 用三问测试打分，判断值不值得拍、先拍哪个 |
| **改造** | 有选题，但角度平 | 用三个机制各转一版，挑转发欲最强的 |
| **生产** | 什么都没有，只有领域 | 从三个机制倒推选题 |

用户没说清楚时，按他给的东西判断：给了选题 → 判断 + 改造；只给了领域 → 生产。

---

## 执行流程

### 第 1 步：写下"裸选题"

把用户的想法压成一句最原始的话，比如"社交货币能让你的视频被更多人转发"。
同时确认**目标观众是谁**（决定"转给谁"）。用户没给就从选题本身推断，推断不出来再问，最多问一轮。

### 第 2 步：三问测试（判断）

| 测试 | 看什么 | 过 / 不过 |
|---|---|---|
| ① 看完会转给谁？ | 具体的人和场景（微信群、同事、家长群、某个朋友） | 答不出具体对象 = 不过 |
| ② 转出去让他显得____？ | 聪明 / 有品位 / 消息灵通 / 有态度 / 懂朋友 | 填不上，或填出来是负面的 = 不过 |
| ③ 饭桌测试 | 把核心观点当一句话说出口 | 对面只会"哦" = 不过 |

再加一个**丢面子测试**（最常被忽略）：

> ④ **转发它，会不会暴露转发者的缺陷？**
> "脱发了怎么办"——转出去等于承认自己秃。
> "孩子不听话怎么办"——转出去等于承认自己不会教。
> "怎么让视频有人转"——转给朋友等于暗示"你的视频没人转"。

给出结论：**值得拍 / 改了再拍 / 不建议拍**，并说清楚是哪一问没过、为什么。

常见的"不过"原因：
- **讲的是概念，不是发现**：复述书本知识，没有非凡性
- **只会收藏，不会转发**：同行干货的天然命运，自己偷偷学
- **转发等于自曝其短**：问题类内容让转发者当了"病人"
- **自相矛盾**：讲"怎么让人转"的视频，自己没人转

### 第 3 步：用三个机制各改一版（改造）

每一版都写清楚：
- **新的选题 / 钩子句**
- **用了哪个机制**
- **对比**：改前 vs 改后，转发的人分别会显得怎样
- **转给谁 + 转发者的角色**
- **重新过一遍饭桌测试**

### 第 4 步：推荐一版，说理由

推荐时优先看：
1. **有没有画面 / 对比**：观众 3 秒能不能看懂，不用先解释概念
2. **靠不靠权威**：好的改法让观众"自己看见"，不需要"信你"。用户没有足够权威时，优先选靠对比和事实证明的版本
3. **圈外人会不会转**：只有同行会转的选题，天花板低

其他版本说明各自适合什么情况（要互动选哪个，要立人设选哪个）。

### 第 5 步（可选）：给开头和结尾建议

- **开头**：用反常识的那句话当钩子。说得绝对的钩子，**10 秒内要收窄**（"有一类内容……"），不然评论区会抬杠，也有夸大的嫌疑
- **概念后置**：先给例子让观众感受到，再说出它叫什么。一上来讲概念就成了上课
- **结尾**：给转发一个体面的场景。好的结尾让转发变成送人情，而不是挖苦对方（"转给你那个内容做得很好、就是没人转的朋友"）

## 改造工具箱（常用的改法）

| 改法 | 改前 | 改后 |
|---|---|---|
| **别让转发者当病人** | "脱发了怎么办" | "熬夜党保住发际线的 3 个习惯" |
| **从"你缺什么"改成"厉害的人怎么做"** | "孩子不听话怎么办" | "高情商父母从不说的 3 句话" |
| **当嘴替：替观众说他不敢说的话** | "打工人要学会拒绝加班" | "下班后回消息，到底算不算加班？" |
| **拍给观众的朋友看** | "减肥的 5 个误区" | "千万别给你那个天天说明天开始减肥的朋友看" |
| **给转发者准备台词** | 讲完原理就结束 | 结尾留一句能被直接复述的话 |
| **把概念变成现象** | "什么是社交货币" | "内容越好，转发越少" |

## 生产选题的公式（从零倒推）

1. **找**：一类"内容很好，但没人转"的视频 / 领域里大众最大的误解 / 我知道但普通人不知道的事 / 能被量化、排名、比较的东西
2. **问**：转发它会让人丢什么面子？或者，转发它能让人显得怎样？
3. **换**：一个让转发者有面子的说法
4. **摆**：前后对比，让观众自己看出差别

## 规则

- **只谈分享性 / 转发性**。完播、点赞、算法推荐不是这个 skill 的判断范围，需要时提示用户用其他 skill（如 Li-流量诊断）
- **不编造数据、案例和背书**。"转发量差十倍""我做了 X 年"这类说法，只能来自用户提供的真实信息；推断出来的规律要标明"这是推断，拍前用自己的数据验证"
- **说真话**：选题不行就直接说不值得拍，再给改法。不要为了鼓励用户硬说"挺好的"
- **别说教**：用户权威不足时，少用"你应该""我告诉你"，多用对比和现象让观众自己得出结论
- 不要堆术语。可以说出"社交货币"这个词，但每个判断都要落到"转给谁、显得怎样"这种大白话上

## 示例

**裸选题**：社交货币能让你的视频被更多人转发

**判断：改了再拍**
- 转给谁：只能转给做账号的朋友，范围窄
- 转出去显得：难填；还暗示朋友"你的视频没人转"（丢面子测试不过）
- 饭桌测试："有个概念叫社交货币。""哦。"
- 问题：讲概念不是讲发现；创作者干货只收藏不转发
- 内核值得保留："人转发是为了经营自己"

**改法一（推荐）**：内在非凡性——"内容越好，转发越少"
- 对比："月薪 5000 怎么省钱"（转出去 = 我很穷） vs "有钱人从来不花的 5 笔钱"（转出去 = 我在学有钱人的思维）
- 饭桌测试："教人省钱的视频，越说穷越没人转。""诶，好像真是。"——过
- 推荐理由：有画面；不靠权威靠对比；视频本身就在证明观点；圈外人也会转

**被否掉的改法和原因**（真实反馈，供判断参考）：
- 内部人感版（"判断选题能不能拍，我只问一句话"）：说教感强，没有足够权威时没人听
